R4A 抄底信号监控 — 执行 SOP（agent 必读）

1. 每次有触发时，必须对每只触发股票完成三段式分析（下跌归因 / 框架分类 / 抄底结论），不可跳过归因步骤。

2. 归因必须基于 WebSearch 得到的近 3 个交易日真实新闻，不得凭通用经验推断。搜索关键词参考 analysis_hook.websearch_template。

3. 框架分类必须从 references/抄底判断框架.md 中的 12 种类型里选一种，必须用框架里明确列出的类型名，不得自造分类。

4. 抄底结论三选一：可抄底 / 不能抄 / 需进一步观察，并给出 200-300 字解释，必须覆盖：
   - 为什么归入该框架类型
   - 应用了哪条操作纪律（先定性？二级思维？分批？）
   - 如果可抄底：建议首笔仓位（如"建仓 1/3 位"）
   - 如果不抄：明确要看到什么信号才重新评估

5. 报告按 templates/报告模板.md 骨架填写，不要改变模板结构。

6. 精简推送稿（步骤 9.5）中，每只触发股票的"结论"行用一句话概括，格式：
   结论：{可抄底/不能抄/需观察}（{首笔仓位建议 或 等待信号描述}）
